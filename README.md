# PCB_EU — контроллер гроубокса

Самостоятельный проект платы EU-0.1 и прошивки для ESP32-WROOM-32E-N4 (4 МБ flash, без PSRAM).

- [Аппаратная часть](hardware/PCB_EU/README.md): схема, плата, BOM, библиотеки, 3D-модели и результаты проверок.
- [Решения и ограничения](hardware/PCB_EU/DESIGN.md): питание, GPIO, механика и оставшиеся испытания.
- [Прошивка и инструкции сборки](softwareEU/README.md): климат, свет, вентиляторы, полив, RTC MCP7940N, INA226 и веб-интерфейс.
- [Проект KiCad](hardware/PCB_EU/PCB_EU.kicad_pro): открывать в KiCad **10.0.7**.

Устаревшее поле статуса прошивки в сохранённом отчёте объяснено в [разделе «Проверки»](hardware/PCB_EU/README.md#проверки). Испытания на реальной плате и производственный выпуск ещё предстоят.

## Проверки и сборка

Команды выполняются из корня репозитория. Для базовых проверок нужны Python 3 и Node.js:

```sh
python hardware/PCB_EU/tools/generate.py
python hardware/PCB_EU/tools/verify.py hardware/PCB_EU/review/netlist.xml
node --test tests/settings.test.cjs
```

Полная аппаратная проверка требует KiCad 10.0.7, Python с `pcbnew` той же версии и Shapely 2:

```sh
python hardware/PCB_EU/tools/run_checks.py --kicad-cli /path/to/kicad-cli --kicad-python /path/to/python-with-pcbnew
```

Общий скрипт `hardware/check_fab.py` включён в репозиторий: его вызывает `run_checks.py`. Исторические упоминания PCB_V1 в комментариях описывают происхождение кода, внешняя копия PCB_V1 для запуска не нужна. Все библиотеки и 3D-модели проекта находятся внутри `hardware/PCB_EU/libraries/`.

Сборка прошивки после установки зависимостей из [softwareEU/README.md](softwareEU/README.md#сборка-и-проверки):

```sh
arduino-cli compile --fqbn esp32:esp32:esp32 softwareEU
```

Файлы `softwareEU/data/` загружаются в SPIFFS отдельно. Список стендовых испытаний приведён в инструкции прошивки.

При переносе выполнены генерация без содержательных изменений, 56 проверок соединений и закупки, 10 тестов веб-интерфейса, проверка локальных ссылок и синтаксиса Python. Сверены 123 исходника из контрольных сумм аппаратного отчёта: отличается только ранее исправленная подпись в `tools/run_checks.py`, как описано в README аппаратной части. Сборка прошивки и полный аппаратный прогон при переносе не повторялись. Окончания строк текста закреплены в `.gitattributes`, исходные байты моделей STEP/STP сохраняются.
