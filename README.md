# PCB_EU — контроллер гроубокса

Самостоятельный проект платы EU-0.1 и прошивки для ESP32-WROOM-32E-N4 (4 МБ flash, без PSRAM).

- [Аппаратная часть](hardware/PCB_EU/README.md): схема, плата, BOM, библиотеки, 3D-модели и результаты проверок.
- [Решения и ограничения](hardware/PCB_EU/DESIGN.md): питание, GPIO, механика и оставшиеся испытания.
- [Прошивка и инструкции сборки](softwareEU/README.md): климат, свет, вентиляторы, полив, RTC MCP7940N, INA226 и веб-интерфейс.
- [Проект KiCad](hardware/PCB_EU/PCB_EU.kicad_pro): открывать в KiCad **10.0.7**.

Затем 24.10.2026 перенесён [PR #94](https://github.com/nikolajevs/ai/pull/94) того же репозитория ([коммит 7fa9410](https://github.com/nikolajevs/ai/tree/7fa9410ddb7977c46e313506acb037693ad571e1)): D501/D601 — SS8PH10-M3/86A, J201 — ZL201-10G, клеммы DG306/DG301R без запаса; оценка закупки 84,67 € → 81,25 €. История предыдущей разработки остаётся в исходном репозитории; номера прежних PR в документации относятся к нему. PCB_V1, её прошивка и инфраструктура VPS в этот репозиторий не входят.

Сохранённые аппаратные отчёты относятся к полному прогону KiCad 10.0.7 от 23.10.2026, выполненному в исходном репозитории (PR #94): ERC и DRC без ошибок, плата полностью разведена. Повторный прогон в этом репозитории 24.10.2026 дал тот же результат, но не сохранялся. Испытания на реальной плате и производственный выпуск ещё предстоят.

Радиатор Q501 крепится на двух запаянных ножках и винте М3 с изолирующей прокладкой и втулкой. Физическая примерка и проверка изоляции выполняются на прототипе.

## Проверки и сборка

Команды выполняются из корня репозитория. Для базовых проверок нужны Python 3 и Node.js:

```sh
python hardware/PCB_EU/tools/generate.py
python hardware/PCB_EU/tools/verify.py hardware/PCB_EU/review/netlist.xml
node --test tests/settings.test.cjs
```

Полная аппаратная проверка требует KiCad 10.0.7, Python с `pcbnew` той же версии и Shapely 2:

```sh
python hardware/PCB_EU/tools/run_checks.py --kicad-cli /path/to/kicad-cli --kicad-python /path/to/python-with-pcbnew
```

Общий скрипт `hardware/check_fab.py` включён в репозиторий: его вызывает `run_checks.py`. Исторические упоминания PCB_V1 в комментариях описывают происхождение кода, внешняя копия PCB_V1 для запуска не нужна. Все библиотеки и 3D-модели проекта находятся внутри `hardware/PCB_EU/libraries/`.

Сборка прошивки после установки зависимостей из [softwareEU/README.md](softwareEU/README.md#сборка-и-проверки):

```sh
arduino-cli compile --fqbn esp32:esp32:esp32 softwareEU
```

Файлы `softwareEU/data/` загружаются в SPIFFS отдельно. Список стендовых испытаний приведён в инструкции прошивки.

Проверки при переносе: 23.10.2026 — генерация без содержательных изменений, 56 проверок соединений и закупки, 10 тестов веб-интерфейса, проверка локальных ссылок и синтаксиса Python; полный аппаратный прогон тогда не повторялся. 24.10.2026 (PR #94) — то же и полный `run_checks.py` на KiCad 10.0.7; сохранённые отчёты `review/` отличаются от нового прогона только датами и путём в `netlist.xml`, поэтому не перезаписывались. На момент прогона контрольные суммы всех 123 исходников из `review/validation.json` совпадали с файлами. После уточнения BOM 24.10.2026 (домашние хидеры, поштучная продажа INA226, актуальные примечания) BOM и скрипты изменены; сохранённые контрольные суммы и сводка закупки относятся к предыдущему состоянию. Подробности — в README аппаратной части; схема и PCB не менялись. Сборка прошивки не выполнялась. Окончания строк текста закреплены в `.gitattributes`, исходные байты моделей STEP/STP сохраняются.
