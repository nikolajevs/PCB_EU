# PCB_EU — Gerber и сверловка, 24.10.2026

Архив для загрузки на фабрику: **PCB_EU_Gerber_b3f286d.zip**.
Источник: [main, b3f286d](https://github.com/nikolajevs/PCB_EU/tree/b3f286d7aa642983e8ee14f5d93cb4674deb81d8), после слияния PR #4. Схема и плата не изменены. Экспорт: KiCad 10.0.5; целевая версия проекта — 10.0.7. Заказ на фабрике не размещался.

## Состав архива

11 файлов в корне ZIP: четыре слоя меди (`.gtl`, `.g1`, `.g2`, `.gbl`), верхняя/нижняя маска (`.gts`, `.gbs`), верхняя/нижняя шелкография (`.gto`, `.gbo`), контур (`.gm1`), раздельные металлизированные и неметаллизированные отверстия (`-PTH.drl`, `-NPTH.drl`). Gerber X2, точность 6 знаков; Excellon в мм с десятичной точкой, абсолютное начало координат, без зеркалирования. Шелкография вычтена из окон маски. Заливки взяты из сохранённой проверенной PCB.

Паяльная паста и сборочные файлы в этот комплект изготовления голой платы не входят. Вспомогательный `.gbrjob` не включён: KiCad записывает в него габарит 100,1 мм по внешнему краю штриха контура и незаданное покрытие `None`. Рабочий контур по оси линий составляет **100×100 мм**; параметры заказа заданы ниже.

## Параметры заказа по проекту

- Четыре слоя: F.Cu → In1.Cu → In2.Cu → B.Cu.
- Размер: **100×100 мм**. Номинальная толщина: **1,6 мм** (модель стека 1,6062 мм).
- Стек JLCPCB **JLC04161H-7628**. Медь: 1 oz снаружи (35 мкм), 0,5 oz внутри (15,2 мкм по проекту).
- Покрытие HASL; переходные закрыты маской с обеих сторон. Цвет маски в этом экспорте не задаётся.
- 409 металлизированных отверстий и 4 неметаллизированных крепёжных отверстия Ø3,2 мм.

## Выполненные проверки

- Свежий ERC: 0 нарушений. Проверка схемы/BOM: 56 пунктов, 498 подключённых выводов.
- Посадочные места: 2198 проверок; размещение: 22 991; связность разводки: 0 неразведённых соединений, 1451 участок дорожек и 345 переходных.
- Геометрический DRC: 0 нарушений; сверка со схемой: 0 расхождений; 0 неподключённых элементов.
- Родной DRC выдал 77 предупреждений об отличиях библиотечных посадок. Для каждого идентификатора UUID проверено соответствие списку из `verify_library_match.py`: отличия только в подрезанной шелкографии, без изменения площадок и прочей геометрии. Общий `run_checks.py --allow-other-version` остановился на распознавании русских описаний этих предупреждений; сводка полного прогона PASS не заявляется. Проверка предупреждений по UUID и последующая производственная проверка выполнены отдельно.
- Проверены стек, 3D-назначения, шелкография и расчёт силовой меди (27 сценариев, без флагов).
- Свежая производственная проверка: **0 FAIL, 3 WARN** — штрих шелкографии 0,15 мм; кольцо переходного 0,15 мм; 82 близкие пары дорожек одной цепи. Это существующие ограничения платы, геометрия не исправлялась при экспорте.
- Независимый парсер Gerbonara прочитал все 9 Gerber-слоёв и оба файла сверловки. Контур замкнут, размер по оси 100×100 мм. Диаметры всех отверстий совпали с PCB, координаты — в пределах округления Excellon 0,0005 мм. Парсер отмечает положение команды G90 в заголовке KiCad, но успешно читает файлы и все отверстия.
- Просмотрены изображения меди, масок и шелкографии, построенные из экспортированных Gerber. На обзорах нижняя сторона показана насквозь, поэтому надписи зеркальные; сами производственные файлы не зеркалировались.
- Целостность ZIP и совпадение каждого файла с экспортом проверены. Исходная PCB побайтово совпадает с коммитом, репозиторий остаётся без изменений.

Сохранённые отчёты `review/` в репозитории не перезаписывались. Экспорт и эти проверки не подтверждают физическую сборку, нагрев, изоляцию радиатора или поведение прототипа. Оставшиеся испытания перечислены в DESIGN.md.
